# Git Lab 1

## Основная часть

- `BarinovaDD` - личная ветка с вводом чисел, суммой и изменением операции через веб-интерфейс GitHub.
- `master` - изменение в master, merge с `BarinovaDD` и разрешение конфликта.
- `main` - итоговая рабочая программа и описание веток.
- `.gitignore` находится в корне репозитория и исключает IDE- и бинарные файлы.

Проверить программу можно командой:

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main
./main
```

## Схемы слияния

- `schema-conflict-master` и `schema-conflict-test` показывают конфликт между C3 и C5 и merge-коммит с разрешением.
- `no-conflict-master-demo` и `no-conflict-test-demo` показывают C3 и C5, изменяющие независимые файлы; merge проходит автоматически.

## Rebase

- `rebase-master-demo` содержит C3.
- `rebase-proof` содержит линейную историю C3 -> C4' -> C5' после rebase. При переносе C5 возник конфликт, который был разрешен.

## Схема C1-C10

Коммиты схемы представлены небольшими файлами-маркерами, чтобы граф был виден отдельно от основной программы.

- `cx-master` указывает на C6 после C5.
- `client` указывает на C9 после C8.
- `server` указывает на C10 после rebase C3, C4 и C10 на client.
- Итоговый линейный порядок: C5 -> C6 -> C8 -> C9 -> C3' -> C4' -> C10.

## Проверка истории

```sh
git log --graph --oneline --decorate --all
git diff 5746eb8 c23f801
```
